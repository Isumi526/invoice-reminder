# 00. プロジェクト概要

## プロダクト名

**Tonton(トントン)** - 「コンコン」と静かにノックするように、自分の代わりに淡々と催促してくれる。
GitHub リポジトリ名は `invoice-reminder`(技術名として独立)。

## ひとことで言うと

**「中小事業者が、未払い請求書の催促を、自分の名前で、自動で、段階的に行えるツール」**

## なぜ作るのか

建設業を中心とした中小事業者にとって、未払い請求は深刻な経営課題です。
しかし既存の解決策には以下の問題があります:

| 既存手段 | 問題点 |
|---|---|
| 自社で催促 | 工数が重く、精神的にも消耗する |
| 債権回収会社 | 成功報酬 20〜30%、少額債権だと割に合わない |
| 弁護士に依頼 | 着手金が高く、零細事業者には敷居が高い |
| 内容証明郵便 | 1 通あたりの手間とコスト、書き方が分からない |

**本プロダクトは「催促業務の効率化ツール」というポジションで、
ユーザー自身による督促を支援する。代行はしない。**

## 誰のためのものか

### プライマリペルソナ

**「小山さん(仮)」**

- 大阪の内装工事会社の社長(従業員 5 名)
- 月間の請求書発行件数 15〜25 件
- 元請けからの支払いは概ね期日通り、孫請け系の取引先で月 1〜2 件の延滞が発生
- 経理は奥さんと自分で担当、専任の経理担当はいない
- スマホは普通に使えるが、PC は最低限の操作のみ
- 法的措置は「角が立つ」と感じて避ける傾向

### セカンダリペルソナ

- 個人事業主のフリーランスエンジニア(亥角さん本人もここ)
- 製造業の下請け事業者
- 運送業の零細事業者
- 士業(社労士・税理士・行政書士)で顧問料の未収が出る人

## 機能スコープ(Phase 1)

最初の 3 ヶ月で出す MVP は以下のみ:

1. **請求書登録**(手入力 + PDF アップロード保管のみ、OCR は Phase 2)
2. **段階的リマインドメール**(ステージ 1〜5、ユーザー名義で送信)
3. **入金確認(手動)**(「入金確認済み」ボタンでスケジュール停止)
4. **ダッシュボード**(未払い一覧、超過日数で色分け、送信履歴)
5. **遅延損害金の自動計算**(契約利率を設定、日割り計算)

詳細は `docs/08-phase-roadmap.md` 参照。

## 機能スコープ(Phase 2 以降)

- マネーフォワード / freee API 連携による入金消込自動化
- 請求書 PDF からの OCR 自動抽出
- 開封・クリックトラッキング(精度限界あり)
- 弁護士・司法書士への送客フロー
- 複数業種テンプレート展開
- sido との Webhook 連携(工事完了 → 請求書発行待ちキュー)

## 成功指標

### Phase 1(3 ヶ月)

- β顧客 1 社(シード社)で 1 ヶ月運用、未払い回収率の改善を計測
- メール到達率 95% 以上
- 誤送信ゼロ

### Phase 2(6 ヶ月)

- 有料契約 5 社獲得
- 月次解約率 5% 以下
- マネフォ連携の入金消込精度 80% 以上

### Phase 3(12 ヶ月)

- 有料契約 20 社、MRR 20 万円
- 建設業以外の業種 1 つに展開
