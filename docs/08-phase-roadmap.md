# 08. Phase ロードマップ

## Phase 1: MVP(3 ヶ月)

### ゴール

β顧客(seed 社)が 1 ヶ月実運用できる最小機能で出す。

### スコープ

#### 認証・組織
- [ ] Supabase Auth(Email + Magic Link)
- [ ] 組織作成・メンバー招待(最大 3 名)
- [ ] プロフィール編集

#### 取引先(債務者)管理
- [ ] 取引先の登録・編集・削除
- [ ] 一覧表示・検索
- [ ] CSV インポート(任意、Phase 1 後半)

#### 請求書管理
- [ ] 請求書の手入力登録
- [ ] PDF ファイルアップロード(保管のみ、OCR なし)
- [ ] 一覧・フィルタ・ソート
- [ ] 詳細表示
- [ ] 入金確認(手動、「入金確認済み」ボタン)
- [ ] 部分入金の手動記録

#### リマインドメール
- [ ] 登録時に S1〜S5 の reminder を自動スケジュール
- [ ] Vercel Cron による日次送信
- [ ] SendGrid 経由でユーザー名義送信
- [ ] 送信履歴の表示
- [ ] バウンス時の自動停止
- [ ] 送信前のキャンセル(ダッシュボードから)

#### 文面・テンプレート
- [ ] 固定テンプレート 5 段階(弁護士監修済み)
- [ ] 組織情報の自動差し込み(会社名・代表者名・住所・電話)
- [ ] 振込先情報の自動差し込み
- [ ] 遅延損害金の自動計算と表示

#### 設定
- [ ] 組織情報の編集
- [ ] 銀行口座情報の登録(1 口座のみ)
- [ ] 送信者情報の検証(マジックリンクでドメイン確認)
- [ ] リマインド一時停止スイッチ

#### ダッシュボード
- [ ] サマリ KPI(未払い総額・期限間近・超過件数)
- [ ] 対応必要な請求書の一覧
- [ ] 直近の送信履歴

#### 課金
- [ ] Stripe で月額プラン(Lite / Standard / Pro)
- [ ] トライアル 14 日間
- [ ] Stripe Customer Portal で解約・プラン変更
- [ ] Webhook で plan 同期

#### 監査・ログ
- [ ] `audit_logs` への書き込み(主要操作)
- [ ] 送信履歴の永続化(編集不可)

### 出さない機能(Phase 1)

- OCR、会計連携、開封トラッキング、複数口座、API、業種別テンプレート、複数言語、モバイルアプリ

### 完了基準

- [ ] seed 社で 1 ヶ月運用、未払い回収率データを取得
- [ ] 誤送信ゼロ
- [ ] メール到達率 95% 以上
- [ ] 弁護士監修テンプレートで本番送信
- [ ] 利用規約・プライバシーポリシー公開
- [ ] 監査ログが全主要操作で書かれている

### 期間目安

- **月 1**: 認証・組織・取引先・請求書登録・基本 UI
- **月 2**: リマインドスケジューラ・メール送信・SendGrid 統合・Stripe 統合
- **月 3**: 監査ログ・テンプレート整備・弁護士監修・β運用開始

## 中長期(12 ヶ月以降)

### 全力AIラボのプロダクトポートフォリオ

- Tonton(債権管理)を主軸プロダクトとして単独成長させる
- sido(施工台帳)とは独立して展開、必要に応じてバンドル販売をオプション提供
- 第 3 プロダクトの企画(請求書発行 SaaS or 工事原価管理 SaaS が候補)
- 全力AIラボ自体を「中小事業者向けの AI 実装パートナー」としてブランディング

### 撤退・売却の検討タイミング

以下のタイミングで継続 / 売却 / クローズを判断:

- 24 ヶ月時点で MRR 30 万円未到達 → 戦略見直し
- 大手競合が同価格帯で参入してきた → 差別化 or M&A
- 亥角さんのキャリア方針が変わった → 売却検討

## 進捗管理

- 月次で seed 社・全力AIラボ内部で進捗レビュー
- 四半期ごとに本ドキュメントを更新
